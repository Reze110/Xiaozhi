# 小智 · 智能蘑菇仓

> 基于物联网技术的全自动蘑菇培育与仓储管理系统

---

## 项目简介

**小智智能蘑菇仓**是一套集环境感知、自动控制、数据分析于一体的智能化蘑菇种植与仓储管理系统。系统通过部署多种传感器实时采集温度、湿度、CO₂浓度、光照等环境参数，并结合自动控制执行器（加湿器、通风扇、补光灯、加热器等），为蘑菇的生长提供最佳的培育环境。同时系统配备移动端 App 及 Web 管理平台，实现远程监控与管理。

---

## 功能特性

- **实时环境监测**：温度、湿度、CO₂浓度、光照强度全天候采集与展示
- **自动化控制**：根据预设阈值自动开启/关闭加湿器、通风扇、补光灯、加热器等设备
- **数据记录与分析**：历史环境数据存储，支持图表化分析，辅助优化种植方案
- **异常告警**：环境参数超出阈值时即时推送告警通知（App / 短信 / 邮件）
- **远程管理**：通过手机 App 或 Web 平台随时随地查看仓内状态并手动调控设备
- **多仓管理**：支持同时管理多个蘑菇仓，统一监控，分区管理
- **生长周期管理**：记录每批次蘑菇的播种、出菇、采收等关键节点，追踪产量数据

|------|-------------|------|

| 通风扇 | 直流轴流风扇 | 换气与 CO₂ 控制 |
| 补光灯 | LED 植物生长灯 | 提供适宜光照 |
| 加热器 | PTC 加热器 | 低温环境保温 |
| 摄像头（可选）| ESP32-CAM | 远程实时监控画面 |

## 快速开始

### 1. 硬件接线

请参考 `docs/wiring_diagram.pdf` 完成传感器与执行器的接线。

### 2. 固件烧录

```bash
# 安装 esptool
pip install esptool

# 烧录固件（以 ESP32 为例）
esptool.py --chip esp32 --port /dev/ttyUSB0 write_flash -z 0x1000 firmware.bin
```

### 3. 配置 Wi-Fi 与服务器

设备首次上电后会开启 AP 热点 `Xiaozhi-XXXX`（`XXXX` 为设备 MAC 地址末 4 位，例如 `Xiaozhi-A1B2`），使用手机连接后访问 `192.168.4.1` 完成以下配置：

- Wi-Fi SSID / 密码
- 云端服务器地址
- 设备编号

### 4. 部署云端服务

```bash
# 克隆项目
git clone https://github.com/Reze110/Xiaozhi.git
cd Xiaozhi

# 安装依赖
npm install          # Web 端
pip install -r requirements.txt  # 后端服务

# 启动服务
docker-compose up -d
```

### 5. 访问管理平台

浏览器打开 `http://<服务器IP>:3000`。系统首次启动时会要求设置管理员密码，请设置一个**强密码**（至少 12 位，包含大小写字母、数字及特殊字符），设置完成后方可进入管理平台。

## 告警阈值说明

系统内置告警阈值可在管理平台「设置 → 告警规则」中自定义，默认配置如下：

| 参数 | 低值告警 | 高值告警 |
|------|---------|---------|
| 温度 | < 10 °C | > 30 °C |
| 湿度 | < 60 % | > 98 % |
| CO₂ | — | > 3000 ppm |
| 光照 | — | > 1000 lux |

## 常见问题

**Q: 设备上电后无法连接 Wi-Fi？**  
A: 请确认 Wi-Fi 密码正确，并确保路由器使用 2.4 GHz 频段（ESP32 不支持 5 GHz）。

**Q: 传感器数据显示异常或为零？**  
A: 检查传感器接线是否牢固，并确认供电电压与传感器规格一致。可在设备管理页面触发「传感器自检」功能。

**Q: 如何添加新的蘑菇仓？**  
A: 在管理平台「设备管理 → 添加设备」中输入设备编号，完成绑定后新仓将出现在仓库列表。

**Q: 数据多久上传一次？**  
A: 默认每 30 秒上传一次，可在固件配置中修改 `UPLOAD_INTERVAL` 参数（单位：秒）。
